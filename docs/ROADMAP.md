# SimDeck roadmap

Planned for a future version.

- **Other games through SimHub.** Connect the companion to SimHub (the free SimHub Property Server plugin gives live values
  over TCP and can trigger SimHub controls), so lamps, gauges and readings work in the ~110 games SimHub reads, mapped onto
  SimDeck's own reading keys so profiles work unchanged.
- **Built-in game connections** where a game offers its own interface, starting with the ones that can also take commands:
  Microsoft Flight Simulator (SimConnect: read values and fire cockpit events), ETS2 / ATS (telemetry SDK), Assetto Corsa
  Competizione and Assetto Corsa (shared memory), Farming Simulator 25 (a script mod like the BeamNG one). Read-only
  telemetry for iRacing, rFactor 2 / Le Mans Ultimate, F1 and Forza. SnowRunner and MudRunner have no data interface.

Done:
- 1.5: the BeamNG Vehicle page in groups, with search and favourites.
- 1.4.1: the companion installs and updates the BeamNG mod.
- 1.4: live readings from BeamNG (temperatures, boost, fuel, G, brakes per wheel, any electrics signal) with a Gauges page;
  a Tuning page like the game's Tuning menu; grouped, searchable pickers for commands and readings.
- 1.3: edit layouts from the Windows companion (Layouts page); presets and copy / paste across pages and profiles on the
  phone; theme extras: optional control sounds, the four-way hat, the inclinometer gauge (roll and pitch from the BeamNG
  mod), the master-warning lamp and a backlight colour per control.
- 1.2: equipment themes (airliner, light aircraft, heavy equipment, agriculture, truck and bus, road car, overland,
  motorsport) with round buttons and dial gauges, panel groups, night lighting and theme-follows-vehicle in BeamNG.
